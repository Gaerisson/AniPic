# AniPic 3.18 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Simplifier les parcours photo/équipe demandés et publier une release web vérifiée.

**Architecture:** Conserver React/Fastify/SQLite et les composants existants. Séparer les lots de fichiers pour permettre une réalisation indépendante, puis intégrer et tester ensemble. Les choix d’adoption et de conservation ont été confirmés par l’utilisateur le 15 novembre 2026.

**Tech Stack:** Node 24, React 19/Vite, Fastify 5, SQLite, Sharp, tests Node.

**Spec:** `docs/superpowers/specs/2026-11-15-anipic-318-design.md`

## Global Constraints

- Aucune publication de AGENTS.md, base de démonstration, clé ou archives privées.
- Conserver les données restaurées ; aucune purge activée par défaut ni déploiement NAS.
- Garder l’APK native en 3.14.0 et les dépendances du lockfile.
- Les améliorations ne doivent pas élargir les permissions existantes.
- Charger l’environnement PowerShell local avant les commandes ; limiter les validations lourdes simultanées sur ce PC.

## Review Focus

- Une référence privée ou une suggestion SPA indisponible ne doit pas produire un accès indu ou sélectionner silencieusement un animal.
- Une décision de présence courte ne doit jamais être confirmée par une minuterie globale.
- Un clic de module désactivé depuis un ancien onglet reste refusé côté API.
- Une correction ignorée et une réponse asynchrone tardive ne doivent pas écraser le texte de travail.
- Les statistiques anonymes ne doivent pas enregistrer un identifiant, une URL sensible ou produire des visiteurs uniques fictifs.
