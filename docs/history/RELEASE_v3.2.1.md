# AniPic 3.2.1 — Correctifs d’affichage

Dans « Photos à trier », la fenêtre d’attribution affiche désormais le portrait du site SPA quand l’animal n’a pas encore de photo locale. Les suggestions utilisent le même composant et chaque référence porte un petit repère SPA.

Les visuels et bannières réservent un espace au logo et à la signature pour éviter leur chevauchement, même avec un grand logo. Le modèle « Logo SPA » reste entier au format story. Dans les séquences vidéo, le logo est légèrement descendu sous les statistiques ; cette composition est partagée par le bilan, les fonds animés et l’écran TV.

Pas de migration de données ni de dépendance ajoutée. Les vidéos déjà exportées restent inchangées ; relancer leur génération pour appliquer la correction. Les fonctionnalités de la [version 3.2](RELEASE_v3.2.md) sont conservées.
