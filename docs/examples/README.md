Cinq propositions A4 portrait créées selon la charte simplifiée SPA fournie. Le profil Nala et ses informations sont fictifs, avec des photographies d’illustration.

- [SPA institutionnel](affiche-spa.pdf)
- [Éditorial](affiche-editorial.pdf)
- [Liquid glass](affiche-glass.pdf)

Les PNG d’aperçu sont fournis à côté des PDF. Dans l’application, le téléchargement PNG imprime à 300 dpi ; ces PNG d’aperçu sont plus petits. Les fichiers `affiche-a4` sont un alias du modèle SPA institutionnel pour conserver les anciens liens.
